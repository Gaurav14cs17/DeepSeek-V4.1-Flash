## architecture notes
deepseek v4.1 flash uses a causal encoder decoder called ced.
the encoder builds global memory for the long prompt.
the decoder projects keys and values from the encoder final states.
this nearly halves prefill compute for agent workloads.

compressed sparse attention two has three modes.
full mode builds main kv and selects top indices.
reindex mode reuses main kv but refreshes the top indices.
reuse mode shares both the kv cache and the selected indices.
every layer still runs sliding window attention for local context.

the main kv cache can be stored in fp4 to save memory.
swa bounded replay rebuilds local state from the last window only.
engram stores ngram patterns in large tables like host memory.
mixture of experts activates only a few experts per token.

## q and a style
question what is ced
answer causal encoder decoder that shares global kv from the encoder

question what is csa2
answer compressed sparse attention with full reindex and reuse modes

question why fp4 kv
answer to shrink the global cache bytes per token

question why swa bounded replay
answer to avoid storing sliding window kv on disk

question what is engram
answer conditional memory via hashed ngram lookup tables
